## Daily loop

1. Each agent reviews memory + open tasks in its lane (`daily-agent-review.py`).
2. Hermes adds leverage / money-saving alerts.
3. Summaries land in the 7:30 AM Chicago Boss brief.
4. Data keeps OSINT / scraper / chat-extract running; Pentest stays defensive.
5. Jarvis still escalates to the OpenRouter frontier model when GPT is thin, or when Boss says **escalate**.
